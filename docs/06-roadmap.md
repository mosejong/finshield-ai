# 06. Four-week Roadmap

## Week 1 — Evidence & scope
- 공식 통계/사례 조사
- 사회초년생 vs 소상공인 결정
- 기존 서비스 분석
- 데이터셋 확보/라이선스 확인
- fraud taxonomy v1
- threat model
- MVP 요구사항 확정
- baseline 설계

**Exit:** 문제정의와 데이터가 근거로 방어 가능해야 함.

## Week 2 — Detection core
- preprocessing
- risk signal extraction
- classifier baseline
- risk engine
- scenario engine
- evaluation golden set
- FastAPI endpoints

**Exit:** UI 없이 API만으로 E2E 분석 가능.

## Week 3 — Evidence + product
- 공식 대응자료 knowledge base
- retrieval
- LLM explanation
- output guardrails
- frontend
- DB/logging
- Docker/deployment

**Exit:** 외부 URL에서 MVP 사용 가능.

## Week 4 — Validation & contest
- 모델/규칙 비교평가
- adversarial/edge cases
- latency 측정
- UX 개선
- 제출용 기능명세
- 기획서
- 데모 시나리오
- 시연 영상
- 발표/Q&A 자료

**Exit:** 재현 가능한 수치 + 안정적 데모 + 제출물 완료.
