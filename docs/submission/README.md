# 제출용 붙여넣기 원고

주최 측 한글(HWPX) 양식 두 장에 **그대로 붙여넣기 위한 평문**이다.

| 파일 | 대상 | 칸 |
|---|---|---|
| [`form1-plan-paste.txt`](form1-plan-paste.txt) | 첨부1 「2026 금융 AI Challenge 기획서」 | 7칸 |
| [`form2-spec-paste.txt`](form2-spec-paste.txt) | 첨부2 「2026 금융 AI Challenge 기능 명세서」 | 5칸 |

## 왜 `.md` 가 아니라 `.txt` 인가

원고의 원본은 [`../38-submission-forms.md`](../38-submission-forms.md) 이고 그것은
마크다운이다. 마크다운을 한글에 붙이면 **표는 `|` 가 그대로 찍히고, 코드펜스는
백틱 세 개가 그대로 남고, `**굵게**` 는 별표가 보이고, `> 인용` 은 꺾쇠가 된다.**
심사자가 읽는 것은 렌더링된 화면이 아니라 PDF 라서, 이 문자들이 그대로 인쇄된다.

그래서 같은 내용을 **개조식 평문**으로 한 번 더 옮겼다. 두 `.txt` 에는 표도,
코드펜스도, 굵게 표시도, 백틱도 없다. 파이프 표는 들여쓴 항목으로, 파이프라인
그림은 번호 목록으로 바꿨다.

## 쓰는 법

1. `.txt` 를 열어 `━━━ [N칸] … ━━━` 구분선 **사이의 본문만** 복사한다.
   구분선 줄 자체는 복사하지 않는다.
2. 한글에서 [편집] → [골라 붙이기] → **텍스트 형식**으로 붙인다.
   그냥 붙이면 서식이 딸려 들어가 표 칸이 밀린다.
3. 12칸을 다 채운 뒤 **PDF 로 변환**한다 (요강 명시).

## 사람이 채우는 칸

두 장 모두 **같은 값**이 들어가야 한다. 따로 심사되므로 한 장만 적거나 두 장이
다르면 같은 참가자의 산출물로 묶이지 않는다.

- 팀명 : **daker.ai 의 현재 참가 상태를 먼저 확인하고 그 값을 옮긴다.**
  팀 등록을 마쳤으면 `FinShield AI`, 아직 개인 참가면 `모세종`.
  **두 장에 같은 값을 적는다** — 한 장만 달라도 다른 참가자로 보인다
- 구성원 성명 : `모세종` — 1인이라 팀장/팀원 구분도 순서도 없다

팀 등록을 자동으로 하지 않는 이유는 `../38-submission-forms.md` 0절에 적었다 —
요강이 개인 참가를 팀 신청 없이 허용하고 있어, 지금 팀을 만드는 것은 제출
직전에 참가 형태를 바꾸는 일이 된다.

## 고칠 때의 순서

**`../38-submission-forms.md` 를 먼저 고치고, 그다음 이 두 `.txt` 를 맞춘다.**
반대로 하면 원고가 두 벌로 갈라지고, 어느 쪽이 제출본인지 알 수 없게 된다.
숫자를 고칠 때는 `docs/35`·`docs/36`·`docs/32`·`docs/33` 도 함께 봐야 한다 —
한쪽만 고치면 제출물끼리 숫자가 갈라진다.

## 이 폴더에 넣지 않는 것

- **완성된 PDF 와 HWPX.** 기획서는 예선 기간 중 아이디어 유출 방지를 위해
  비공개로 게시된다. 저장소는 공개 대상이 아니지만, 제출본 바이너리를 여기 두면
  원고와 제출본이 어긋났을 때 어느 쪽이 맞는지 판단할 근거가 사라진다.
  텍스트 원고 한 벌만 둔다.
