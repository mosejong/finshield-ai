# 19. Wealth Guidance v0.1

## 목적

재테크에 관심 있는 사용자가 투자상품을 고르기 전에 자신의 금융생활을 점검하고
공식 교육으로 이동할 수 있는 입구를 제공한다. 이 기능은 투자자문이나 상품 추천이
아니며 수익률·원금·매매 시점을 예측하지 않는다.

## 교육 흐름

1. 소득·지출, 저축·투자, 자산·부채를 구분해 돈의 흐름 파악
2. 재무 목표와 저축·소비 계획 확인
3. 대출·신용 현황과 공식 상담 창구 확인
4. 손실 가능성·비용·집중 위험을 이해한 뒤 투자 기초 학습

위 순서는 화면의 학습 진행 순서이며 개인별 최적 행동을 판정하는 규칙이 아니다.

## API 계약

`GET /api/v1/guidance/wealth`

- 입력·query 없음
- version과 일반 교육 범위 고지
- 순서가 고정된 교육 module 4개
- module별 점검 질문·다음 학습 행동·source ID
- 검토일이 포함된 공식 source catalog

정적 JSON은 Pydantic으로 검증하며 module code/order, source ID/URL, 검토일,
module-source 양방향 지지를 확인한다. 런타임 외부 요청은 없다.

## 금지선

- 특정 주식·채권·펀드·ETF·코인 추천
- 매수·매도·갈아타기 시점 제시
- 목표·예상 수익률 또는 원금 보장
- 사용자의 계좌·보유종목·거래내역 수집
- 프론트에서 재무상태를 계산해 투자 가능 여부 판정

개인 상황에 맞춘 판단이 필요하면 공식 재무상담 또는 자격을 갖춘 전문가 확인으로
연결한다.

## 공식 근거

- 서민금융진흥원 `청년 모두를 위한 재무상담`
- 서민금융진흥원 `비대면 금융교육`
- 서민금융진흥원 `신용·부채관리 컨설팅`
- 전국투자자교육협의회 설립 목적과 자기판단 원칙
- 전국투자자교육협의회 금융상품 설명의무와 원금손실·수수료 교육
- 전국투자자교육협의회 분산투자 기초 교육

각 URL과 검토일은 `app/data/wealth/guidance_v0_1.json`에서 관리한다.
