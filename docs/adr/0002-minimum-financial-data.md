# ADR-0002: Minimum Financial Data Collection
Status: Accepted for MVP
Date: 2026-08-11
## Decision
Prefer age band, employment status, justified income/expense values or bands, liquid assets, debt balances/payments, credit-score band, business status and financial goal.
Do not collect RRN, bank credentials, OTP/passwords, full card credentials or unnecessary account numbers.
Sex/gender is not a default feature; add only for verified eligibility or justified UX need.
## Consequence
Less granular personalization in exchange for lower privacy/security risk.
