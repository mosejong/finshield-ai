# 21. FinancialProfile Derived Metrics v0.1

## 목적

사용자가 입력한 최소 금융정보로 현재 월 현금흐름과 비상자금 범위를 재현 가능한
결정론적 계산으로 보여준다. 은행의 대출 심사 지표나 투자 적합성 판단을 만들지 않는다.

## API

`GET /api/v1/profiles/{profile_id}/metrics`

- 저장된 profile을 backend에서 다시 읽어 계산한다.
- 브라우저는 profile ID만 전송하며 소득·부채 원문을 다시 보내지 않는다.
- profile이 없으면 404이며 mock이나 빈 지표로 대체하지 않는다.
- 응답은 profile `updated_at`, 계산 원값, 표시용 지표, 가정, disclaimer를 포함한다.

## 결정론적 계산

```text
월 현금흐름 = 월 순소득 - 고정지출 - 생활비 - 월 부채상환액
월소득 대비 상환액(%) = 월 부채상환액 / 월 순소득 × 100
비상자금 기간(개월) = 유동자산 / (고정지출 + 생활비)
비상자금 목표액 = (고정지출 + 생활비) × 입력한 목표 개월
비상자금 부족액 = max(목표액 - 유동자산, 0)
```

- 비율과 기간은 소수 첫째 자리에서 `ROUND_HALF_UP`한다.
- 월 순소득이 0원이면 상환 비율은 `null` / `계산 불가`다.
- 고정지출과 생활비 합계가 0원이면 비상자금 기간은 `null` / `계산 불가`다.
- 0으로 나눈 값을 0% 또는 무한대로 표시하지 않는다.

## 표현 경계

- 현금흐름 tone은 양수/0/음수만 사용한다.
- 비상자금 tone은 사용자가 입력한 목표 개월의 달성 여부만 사용한다.
- 상환 비율에는 임의의 좋음/나쁨 임계값을 적용하지 않는다.
- 월소득 대비 상환액은 공식 DSR과 다르다고 항상 표시한다.
- 특정 상품, 대출 승인 가능성, 투자 가능 금액을 추천하지 않는다.

## 개인정보·수명주기

추가 개인정보 필드는 없다. 계산 결과는 별도 저장하지 않고 현재 process-local profile에서
요청 시 계산하므로 profile 교체 후 즉시 바뀌고 profile 삭제·서버 재시작 후에는 404가 된다.
