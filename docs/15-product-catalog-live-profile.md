# 15. Official Product Catalog Live Profile

> 측정일: 2026-08-12 16:34 KST
>
> 공식 기준월: 202607
> 데이터셋: 금융위원회 `서민금융상품기본정보`

## 목적

상품 cache, 중복 제거와 FinancialProfile 기반 filtering을 구현하기 전에 최신
공식 데이터의 실제 형태와 결측을 측정한다. 이 문서는 eligibility나 상품 품질을
판정하지 않고 데이터 처리 규칙을 정하기 위한 관측 결과만 기록한다.

## 재현 방법

프로젝트 루트 `.env`에 공공데이터포털에서 발급된 `일반 인증키`를 설정한 뒤
다음을 실행한다.

```powershell
.\.venv\Scripts\python.exe -m scripts.profile_product_catalog --env-file .env --page-size 100
```

프로파일러는 KST 현재 월부터 역순으로 첫 활성 기준월을 찾고, 해당 월만 최대
100건 단위로 전부 조회한다. 키와 325건 원문 전체는 출력·저장하지 않으며 집계
JSON만 표준 출력한다.

## 다음 단계 설계 제약

- cache key는 최소 provider + 기준월 + page/query를 포함한다.
- cache 응답에는 `fetched_at`, 기준월과 source reference를 유지한다.
- 최신월 325건만 대상으로 먼저 in-memory TTL prototype을 만든다.
- 상품명 기준 자동 dedup은 하지 않는다.
- 금리·한도·상환방법 누락을 0이나 기본값으로 바꾸지 않는다.
- filtering 결과는 `eligible`이 아니라 `potential_match`, `mismatch`,
  `needs_review` 수준으로 표현한다.
- 금리 없는 79건과 용도 없는 28건을 단순 하위 순위 또는 탈락 처리하지 않는다.
