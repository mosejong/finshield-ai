# 창구의 독점 — held-out v1.2 와 진짜 기관의 통지문

2026-08-24

## 한 줄

**진짜 기관도 문자를 보낸다.** 열한 회차 동안 이 셋들은 사칭 문장만 모아 왔고, 그래서
`authority_impersonation` 의 무조건 층 — 기관명이 나오면 요구가 없어도 켠다 — 이 한 번도
값을 치르지 않았다. 경찰청·검찰청·법원·금감원이 실제로 보내는 통지문 열두 건을 처음으로
같은 자리에 놓자 **여덟 건이 사칭으로 읽혔다.** 갈리는 자리는 기관명이 아니라 **창구**였고,
다섯 곳을 고쳐 f1 0.4384 → **0.7532**, 오탐 10 → **1**, 등급 천장과 금지 행동 회피를
**1.0000** 으로 보냈다. 값은 두 곳에서 치렀고 둘 다 결과 파일에 그대로 남겼다.

## 0. 이번 회차의 방향

| 회차 | 수정의 방향 | 값을 치르는 자리 |
|---|---|---|
| v0.2~v0.5 | 넓히기 | 정상 문장 (오탐) |
| v0.6 | 좁히기 | 사기 문장 (미탐) |
| v0.7 | 올리기 | 정상 문장의 등급 (천장) |
| v0.8 | 넓히기 5 + 좁히기 1 | 양쪽 다 |
| v0.9 | 갈아 끼우기 + 올리기 1 + 좁히기 1 | 옛 셋의 라벨 |
| v1.0 | 넓히기 5 | 정상 문장 (오탐과 천장) |
| v1.1 | 분모 바꾸기 + 넓히기 3 | 셋 자신 |
| **v1.2** | **천장 세우기 1 + 넓히기 3 + 게이트 1** | **옛 셋의 라벨** |

v1.1 이 닫으면서 남긴 숙제가 정확히 둘이었다.

> **`authority_impersonation` 무조건 층에 정상 사례를 붙인다** (`fh-942`). 진짜 기관의
> 통지문을 재는 정상 사례가 열두 셋 중 어디에도 없다. **재지 않은 판단은 검증된 판단이
> 아니다.**
>
> **`secrecy_isolation` 의 `외부에` 충돌을 결정한다.** 어휘로는 갈리지 않는다 — **자리**에서
> 봐야 한다.

이번 셋은 그 둘을 재려고 만들었다. 둘 다 예상보다 크게 비어 있었다.

### 갈리는 것은 기관명이 아니라 창구다

진짜 기관은 **읽는 사람이 이 문자 없이도 갈 수 있는 창구**를 댄다. 경찰청은 이파인을,
검찰청은 형사사법포털을, 법원은 민원실과 전자소송 홈페이지를, 금감원은 파인과 1332 를,
국세청은 홈택스를 댄다. 창구를 대는 것은 **읽는 사람을 메시지 밖으로 내보내는 행위**다.

사칭은 그러지 못한다. 대는 순간 읽는 사람이 거기로 가서 거짓이 드러나기 때문이다. 그래서
사칭은 둘 중 하나를 한다.

- **창구를 주지 않는다.** "담당 조사관이 곧 연락드릴 예정이니 대기해 주십시오."
- **진짜 창구를 밀어내려고만 댄다.** "홈택스 말고 저희 전용 시스템으로만", "1332는 지금
  연결이 안 되니", "공식 홈페이지에는 아직 반영되지 않은 건입니다."

두 번째가 이번 회차의 핵심이다. **창구 이름이 나온다는 것은 억제의 표지였는데, 그 표지를
그대로 갖추고 부정만 덧붙이는 어형이 실제로 존재한다.** 억제 규칙을 노리는 가장 싼 우회다.

## 3. 다섯 수정 (`284aeba`)

### D1 — 갈 수 있는 창구를 대면 통지문이다

무조건 층은 상쇄가 없었다. `_safe_context_suppresses` 에 천장을 세운다.

```python
def _names_reachable_counter(normalized: str) -> bool:
    if not any(_is_channel_referral(clause) for clause in _demanding_clauses(normalized)):
        return False
    if COUNTER_EXCLUSION_PATTERN.search(normalized):
        return False
    if CHANNEL_MONOPOLY_PATTERN.search(normalized):
        return False
    return not _has_reader_demand(_open_clauses(normalized))
```

세 개의 빗장이 다 필요하다. **창구를 대고**, **그 창구를 닫지 않고**, **읽는 사람에게
아무것도 요구하지 않는다.** 셋 중 하나라도 빠지면 사칭이 그 자리로 들어온다.

같이 넓힌 것은 창구 **이름**이다.

```
민원실 · 인트라넷 · 이파인 · 경찰민원포털 · 형사사법포털 · 정보포털 파인 · 홈택스 · 카드사 앱
```

기존 목록은 종류 어휘(`홈페이지`·`영업점`·`고객센터`)뿐이었다. **진짜 기관은 종류가 아니라
이름을 댄다.** 그래서 A군 열두 건 중 종류 어휘로 잡힌 것은 넷뿐이었다. `CHANNEL_REFERRAL_VERBS`
에 `연락` 도 넣었다 — "경찰서 대표번호로 연락 주십시오" 가 동사 목록에 없어 빠졌다.

### D5 — 밀어내려고 부른 창구는 창구가 아니다

```python
COUNTER_EXCLUSION_PATTERN = re.compile(
    r"(?:말고|대신에|연결이\s*안\s*되|통화가\s*안\s*되"
    r"|반영되지\s*않|처리되지\s*않|조회되지\s*않|접수되지\s*않)"
)
```

같은 검사를 `_is_prevention_notice` 에도 건다. 예방 안내문 억제는 `공식 홈페이지`·`금융감독원`
같은 표지 어휘로 작동하는데, **표지만 빌려 쓰는 문장이 있다.**

```
fh-1052  "공식 홈페이지에는 아직 반영되지 않은 건입니다. 저희 쪽 확인이 유일한 방법입니다."
```

낱말 `공식 홈페이지` 하나로 모든 신호가 억제됐다. 문장이 하는 말은 정확히 그 반대다.

### D2(부분) — 창구를 화자 하나로 좁히는 것은 고립 요구다

고립 어휘는 `저와만 연락`·`통화를 끊지` 같은 어형 몇 개뿐이었다. 실제 어형은 훨씬 흔한
자리에 있다 — **화자를 가리키는 말에 배타 조사가 붙는다.**

```python
CHANNEL_MONOPOLY_PATTERN = re.compile(
    r"(?:저희|담당자|담당관|담당\s*조사관|담당\s*수사관|이\s*번호"
    r"|전용\s*(?:창구|시스템|번호|회선|라인)|직통\s*(?:번호|회선|라인)"
    r"|안내(?:드린|해\s*드린)|상담창)"
    r"[^.!?\n]{0,12}?"
    r"(?:에서만|으로만|로만|을\s*통해서만|를\s*통해서만"
    r"|만\s*(?:가능|진행|연락|문의|이용|따라|따르)|유일)"
    r"|다른\s*(?:기관|곳|번호|경로|창구)[^.!?\n]{0,8}?(?:문의|연락|이용|확인)하지"
)
```

어휘가 아니라 **자리**로 적었다. 화자 지시어와 배타 조사 사이는 12자까지 열어 둔다 —
"저희 담당 창구에서만", "안내드린 직통 번호로만" 같은 사이 말이 들어간다.

**진짜 기관은 자기를 유일한 통로로 만들지 않는다.** 그럴 필요가 없기 때문이다.

### D3 — `외부에` 는 금지의 대상으로 가른다

`외부에` 는 v1.0 부터 고립 어휘에서 일부러 빼 두었다. 사내 공지의 대외비 문구가 그
어형이기 때문이다(`fh-865`). 그래서 반대쪽도 통째로 비어 있었다.

**고립이 막는 것은 이 연락 자체이고, 기밀 유지가 막는 것은 읽는 사람이 이미 쥔 것이다.**

| 고립 (사기) | 기밀 유지 (정상) |
|---|---|
| 이 건 · 본 건 · 이 통화 · 상담 내용 | 조직개편 초안 · 합격 사실 · 협의 내용 |
| 안내드린 (절차) · 절차상 · 수사상 | 연구 참여자 정보 · 감사 내용 |

```python
EXTERNAL_ISOLATION_PATTERN = re.compile(
    r"(?:" + "|".join(ISOLATION_CONTACT_REFERENTS) + r")"
    r"[^.!?\n]{0,16}?외부[에로](?:는|도|만)?\s*"
    r"[^.!?\n]{0,10}?"
    r"(?:알리|말하|말씀|공유|문의|유출|공개|전하)"
    r"(?:하)?(?:지\s*(?:마|말)|시면|면\s*안\s*[되돼됩됐된될])"
)
```

어미도 함께 잠근다. **금지여야 한다 — 보장은 금지가 아니다.**

```
fh-535 (v0.7 정상)  "개인정보 보호를 위해 상담 내용은 외부에 공개되지 않습니다."
```

`상담 내용` 은 고립 지시어 목록에 있고 `외부에 공개` 도 맞는다. 갈리는 자리는 어미
하나다 — 이 문장은 읽는 사람에게 아무것도 요구하지 않는다. 첫 구현이 이 자리를 밟아
v0.7 에 없던 오탐을 만들었고, 어미 잠금으로 되돌렸다.

세 번째 빗장은 **남겨 두는 집단**이다.

```python
GROUP_EXEMPTION_PATTERN = re.compile(
    r"(?:팀원|부서원|부서|동료|참석자|관계자|실무진|당사자|본인)"
    r"(?:들)?\s*(?:분들)?\s*(?:외에|이외에|말고)"
)
```

```
fh-1028  "인사 발표 전까지 팀원들 외에는 아무에게도 말하지 말아 주세요."
```

전칭 금지 어휘(`아무에게도`)를 갖췄지만 **읽는 사람 곁에 남는 사람이 있다.** 고립은
읽는 사람을 혼자로 만드는 것이고, 예외 집단이 있으면 제3자 확인이 막히지 않는다.

### 예측에 없던 것 — 상태만으로 상대를 끊으라고 하지 않는다

미탐과 무관하게 드러난 결함이다. 신호가 하나도 없는 정상 문장이 상태만으로
`STOP_CONTACT` 를 받았다.

```
fh-1059  "급여 입금 안내: 03/25 2,480,000원 입금되었습니다."   (transferred_money)
fh-1064  "진료 예약이 04/05 15:30으로 확정되었습니다."          (shared_personal_info)
fh-1065  "말씀하신 대금 입금 확인했습니다."                      (transferred_money)
```

회사와, 병원과, 거래처와 연락을 끊으라는 말이 나갔다.

```python
SIGNAL_GATED_STATE_ACTIONS = frozenset({"STOP_CONTACT"})
```

```python
action_codes: set[str] = set(STATE_ACTIONS[state])
if not signals:
    action_codes -= SIGNAL_GATED_STATE_ACTIONS
```

**상태 표의 나머지 행동은 전부 읽는 사람 쪽에서 끝난다** — 증거를 남기고, 창구에
전화하고, 더 넘기지 않는 것이다. `STOP_CONTACT` 만 방향이 반대라서 **상대가 적이라는
판단이 먼저** 있어야 하는데, 상태는 읽는 사람이 무엇을 했는지만 말한다.

**상태는 신호를 대신하지 않는다.** v1.1 이 `STATE_PREVENTION_ACTIONS` 에서 세운 원칙을
`STOP_CONTACT` 로 한 칸 더 민 것이다. 등급은 상태의 몫으로 그대로 올라간다 —
`STATE_MINIMUM_RISK` 는 건드리지 않았다. **재는 것은 등급이 아니라 행동이다.**

## 4. 수정이 서로를 가렸다

첫 구현을 돌리자 `fh-1020`·`fh-1050` 이 여전히 침묵했다. 어형은 분명히 등록돼 있었다.

```
fh-1020  "확인은 저희 담당 창구에서만 가능합니다."
fh-1050  "은행 창구에서는 처리되지 않는 건이라 저희 담당자를 통해서만 진행됩니다."
```

원인은 **순서**였다. `창구` + `에서만` + `가능` 은 창구 안내 어휘·조사·동사를 전부 갖추고
있어서 `_is_channel_referral` 이 그 절을 안내로 세었고, 안내로 세어진 절은 `_open_clauses`
에서 빠진다. **고립 규칙이 검사할 때 그 절은 이미 문장에 없었다.**

같은 어형이 두 판정에서 반대로 작동한다. 그래서 `_is_channel_referral` 이 독점 어형을
만나면 그 절을 안내에서 **실격**시키도록 했다.

```python
if CHANNEL_MONOPOLY_PATTERN.search(remainder):
    return False
```

**창구를 대는 것과 창구를 닫는 것은 반대 방향이다.** 억제 규칙과 탐지 규칙이 같은 표지를
공유하면, 억제가 먼저 도는 한 탐지는 영원히 그 자리를 못 본다.

"접수되었습니다. 담당자가 확인 후 연락드리겠습니다" 는 정상 고객센터의 흔한 문장이다.
**측정할 수 없는 수정은 고친 것이 아니라 옮긴 것이다.**
